# VISCERA Anatomy Studio

The full studio: reference organs from open atlases (HRA, BodyParts3D; CC BY), bounded shape controls, the joint
shape + colour VAE, disease morphology, text commands, the physics lab with a learned liver material, surface vessels,
sculpting, photo-derived surface detail, and GLB / Unity exports. Model administration and the saved-project listing
are disabled on the public server. The demo database does not persist across restarts.

Licences: organ templates CC BY 4.0 (Human Reference Atlas), BodyParts3D CC BY-SA 2.1 JP, surgical photographs CC BY
4.0 (DSAD; DRENDS), and the studio's own procedural, trained and authored assets. Nothing here is clinically validated.
