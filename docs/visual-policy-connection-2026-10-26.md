# One-click local visual-policy tasks

The Run button previously required a successful manual Connect, and a stopped local service produced generic browser-permission advice. Browser permission alone cannot start the Python policy. On the affected Mac, port 8877 had no listener; the foreground launcher depended on a terminal and files under iCloud.

Run now checks fresh policy health itself. It validates the response and model ID before entering the existing guarded task controller. Failed or unready connections start no motion and leave Run available for retry. Stop, Escape, scene changes and unmount cancel pending connections; a late health response cannot initiate motion. The separate Connect button remains a diagnostic option. No skill-precondition, collision, force, displacement, stale-frame or confidence guard is relaxed.

`scripts/install_visual_policy_service.py` installs the pinned runtime and checksum-verified existing trained weights outside iCloud, under the user's Application Support directory. A loopback-only LaunchAgent starts at login and restarts after failure. Reinstall restarts an unchanged job in place to avoid an observed asynchronous bootout/bootstrap race. Readiness is accepted only when port 8877 belongs to the installed job's PID. See the model card for installation and stop commands.

Validation on the production build: TypeScript, 17 focused unit tests, 9 Python protocol tests, and all 13 browser tests passed. Four actual trained-model tasks completed look → grasp → release → finish across the default liver and three disease severities, using three instruction phrasings. Measured inference was 276–590 ms; tool movement began 732–1236 ms after camera arrival, contact occurred at 2849–3343 ms, hold displacement was 3.17 mm and peak simulated reaction was below 0.168 N. Final recovery displacement was below 0.005 mm, with no browser errors. Other cases cover offline, denied and unready services, late health and inference responses, incorrect skills, disconnection while holding, mobile stop controls and stable camera aspect.

The same backend and trained adapter are retained; this is a connection and service-lifecycle correction, not retraining or clinical validation. Browser results, phase captures, installation receipts and published-site verification are archived under `artifacts/visual-policy-connection-2026-10-26`.
