## Visual iteration record

1. Initial review found a pendant-like gallbladder. Its axis and placement were changed to lie along the inferior surface; a four-view render verifies the visible change.
2. Lighting and pigments were revised after the first editor screenshot appeared pale and plastic. An overly periodic normal map was replaced with subtle seeded multiscale noise.
3. Browser tests found a null-reference history capture, a compact-grid zero-width viewport, and an incompatible texture export path. Each was fixed and retested.
4. The first cohort's liver-volume median was 2.85 L with an excessive upper tail for the intended default authoring experience. That immutable cohort remains a stress release. The next release uses correlated dimensions centered on the preview template and a declared 1.2–2.6 L **design band**, which is not a medical reference interval.
5. Probe review uses fixed simulation time and retains the measured residual. Video appearance alone is never treated as a material identification or an anatomical validity test.
6. Learned control bounds were encoded through an invertible logit transform after the earlier unconstrained model failed some bounds checks. Validation acceptance improved from 16/19 to 19/19, at the cost of worse conditional errors. The frozen bounded model then passed 32/32 fresh audit samples and 12/12 unconditional samples. PCA remains the more accurate conditional baseline; the audit did not trigger refitting or model selection.

The next quality milestone requires independently authored anatomical templates and expert-reviewed morphology, plus acquired appearance and mechanical references. More samples from the same recipe cannot substitute for those sources of evidence.
